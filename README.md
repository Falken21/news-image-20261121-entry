A one-page newspaper front page summing up Saturday 21 November 2026's world news in a single 1024×1024 image, built for the [news-image-20261121 bounty on make.fun](https://make.fun/bounty/news-image-20261121).

Six stories: a global AI sell-off crashes markets (lead), a Russian missile hits Kryvyi Rih, the ICJ rules Myanmar committed genocide against the Rohingya, Mexico captures cartel boss "El Chapo Isidro", COP31 talks in Antalya run past their deadline, and a magnitude 6.8 quake strikes off Timor-Leste — plus four one-line briefs in the "JUGA HARI INI" footer strip.

## Run
